Rule Notes

Public data only

This app uses rule/reference sheets from the duty lookup workbook. Customer case workbooks are not included.

232 flags

Manual flags do not create 232 by themselves. The HTS must first match a 232 rule; flags then select duty or exemption numbers.

HTS sequence

When multiple Chapter 99 numbers apply, use 301, then 301 Forced Labor, then 232, followed by the Chapter 1-97 HTS.

Final review

This is a screening tool. Official HTS notes, PGA requirements, AD/CVD, and entry instructions still need review before filing.
